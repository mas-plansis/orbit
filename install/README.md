# Установка Orbit Connect для macOS

Этот каталог содержит последний переходный выпуск `v0.1.16`.

1. Скачайте `OrbitConnect.zip`.
2. Распакуйте архив.
3. Перенесите Orbit Connect в папку «Программы» и запустите.

После установки приложение получает дальнейшие обновления из нового канала:
https://github.com/mas-plansis/orbit-connect/releases

Контрольная сумма находится в `SHA256SUMS`.
