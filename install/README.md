# Установщик Orbit

Для первой установки скачайте файл `orbit-install.tar.gz` из этой папки.

Положите его без распаковки в папку `install` на EXT4-разделе, выбранном как
накопитель OPKG в KeeneticOS. После этого дождитесь завершения установки.

Файл `SHA256SUMS` содержит контрольную сумму установщика. Остальные файлы
репозитория копировать на накопитель не нужно.

Подробная инструкция находится в [INSTALL.md](../INSTALL.md).
