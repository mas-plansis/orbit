# Установка Orbit на Keenetic

## 1. Подготовьте роутер

В разделе компонентов KeeneticOS установите:

- поддержку открытых пакетов OPKG;
- поддержку файловой системы EXT4;
- модули ядра Netfilter для OPKG.

Примените изменения и дождитесь готовности роутера.

## 2. Подготовьте накопитель

Подключите USB-накопитель объёмом от 2 ГБ. Создайте небольшой раздел SWAP и
основной раздел EXT4. Выберите EXT4 как накопитель OPKG.

Форматирование удаляет данные. Не извлекайте накопитель во время установки.

## 3. Скачайте установщик

Откройте папку [`install`](install) в главном разделе репозитория и скачайте
файл `orbit-install.tar.gz`. Это полный комплект для первой установки.

Не распаковывайте и не переименовывайте файл.

## 4. Скопируйте установщик на накопитель

Создайте на EXT4-разделе каталог `install` и положите архив внутрь:

```text
OPKG/
└── install/
    └── orbit-install.tar.gz
```

Другие файлы из репозитория копировать на накопитель не нужно.

## 5. Дождитесь установки

После выбора накопителя OPKG KeeneticOS запустит установщик. Ход работы виден
в системном журнале роутера. Не выключайте Keenetic до сообщения об успешном
завершении.

## 6. Откройте Orbit

Перейдите по адресу:

```text
http://orbit.home
```

Если локальный адрес ещё не появился, откройте
`http://<IP роутера>:3000`.

Создайте локальную учётную запись, добавьте ссылку на источник серверов,
проверьте серверы и выберите устройства, которые должны использовать Orbit.

## Обновление из файла

Для уже установленной Orbit скачайте файл с расширением `.orbit-update`.
Откройте окно обновлений, выберите «Импорт обновления», укажите файл и нажмите
«Применить». Настройки сохраняются, а при ошибке запуска Orbit выполнит откат.
