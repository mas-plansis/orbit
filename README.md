# Orbit Connect для macOS

Приложение в строке меню macOS показывает:

- состояние подключения
- конечный адрес
- маршрут устройства

Orbit узнаёт связанное устройство, даже если его частный Wi-Fi адрес изменился, и автоматически восстанавливает настройки подключения.
